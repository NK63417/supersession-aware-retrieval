last-updated: 2026-07-28

## Report
Nightly batch halted partway. Scheduler showed a non-zero exit on the address
normalisation step.

## Resolution applied
Single record with an unescaped delimiter in the postal field. Corrected the record
with a data fix and re-ran the step; batch completed. No code change required —
the parser handles the case correctly once the record is valid.
